Heapify — 自底向上建堆（下沉 / sift-down）可视化

从最后一个非叶子节点（下标 n/2 - 1）开始，逐个向前处理到根节点，对每个节点做下沉操作。 整体时间复杂度 O(n)，比逐个 push 建堆的 O(n log n) 更快。

当前下沉节点 参与比较的子节点 已完成下沉，堆性质满足
输入数组后点击"建堆"，逐步观察自底向上的下沉过程。
def heapify(arr):
    n = len(arr)
    # 从最后一个非叶子节点开始，往前处理到根节点
    for i in range(n // 2 - 1, -1, -1):
        _sift_down(arr, i, n)

def _sift_down(arr, i, n):
    while True:
        largest = i
        left, right = 2*i + 1, 2*i + 2
        if left < n and arr[left] > arr[largest]:
            largest = left
        if right < n and arr[right] > arr[largest]:
            largest = right
        if largest == i:
            break
        arr[i], arr[largest] = arr[largest], arr[i]
        i = largest


# 使用示例
arr = [4, 10, 3, 5, 1, 15, 20, 17, 8]
heapify(arr)
print(arr)
import heapq

arr = [4, 10, 3, 5, 1, 15, 20, 17, 8]
heapq.heapify(arr)  # O(n)，内部就是自底向上的下沉法
