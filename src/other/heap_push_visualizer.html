Heap Push — 最大堆插入（上浮 / sift-up）可视化

向最大堆插入新元素：先放到数组末尾（下一个空叶子位置），再与父节点反复比较并上浮，直到堆性质恢复。 时间复杂度 O(log n)。

新节点 / 移动中 比较的父节点
点击"推入"，插入一个新值观察上浮过程。
class MaxHeap:
    def __init__(self):
        self.heap = []

    def push(self, value):
        """插入新元素：先放到末尾，再上浮（sift-up）"""
        self.heap.append(value)          # 1. 放到数组末尾（下一个空叶子）
        self._sift_up(len(self.heap) - 1)

    def _sift_up(self, i):
        while i > 0:
            parent = (i - 1) // 2
            if self.heap[parent] < self.heap[i]:
                # 子节点比父节点大，交换，继续向上比较
                self.heap[parent], self.heap[i] = self.heap[i], self.heap[parent]
                i = parent
            else:
                # 堆性质已满足，停止
                break


# 使用示例，对应可视化里的初始堆
h = MaxHeap()
h.heap = [90, 70, 80, 40, 60, 50, 75, 10, 30]
h.push(85)
print(h.heap)
import heapq

# heapq 默认实现的是最小堆
# 如果要模拟最大堆，通常把数值取负存入
min_heap = [10, 20, 15, 30, 40]
heapq.heapify(min_heap)      # O(n) 建堆
heapq.heappush(min_heap, 5)  # O(log n) 插入，内部同样是"放到末尾再上浮"
