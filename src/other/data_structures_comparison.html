常见数据结构性能与应用对比

涵盖数组、链表、栈、堆、队列的时间复杂度、应用场景及面试高频考题

数据结构 查询 (Search) 插入 (Insert) 排序 (Sort) 经典应用场景 高频面试考题 (LeetCode 典型)
数组
(Array)		 按索引: O(1)
按数值: O(n) 		末尾: O(1)
中间/头部: O(n) 		典型算法: O(n log n)
如快排、归并排序
  • 快速随机访问已知索引的数据
  • 多维矩阵表示（图像处理、图邻接矩阵）
  • 实现其他简单数据结构的底座
  • 两数之和 (Two Sum)
  • 三数之和 (3Sum)
  • 寻找旋转排序数组中的最小值
  • 移动零 / 移除元素 (双指针技巧)
链表
(Linked List)		 任意位置: O(n) 已知节点位置: O(1)
未知位置: O(n) 		归并排序: O(n log n)
通常利用归并完成链表自顶向下/向上排序
  • 频繁在中间进行增删操作
  • LRU 缓存淘汰算法（双向链表 + 哈希表）
  • 实现链式栈与链式队列
  • 反转链表 (Reverse Linked List)
  • 环形链表检测 (快慢指针/Floyd判圈)
  • 合并两个有序链表
  • 删除链表的倒数第 N 个结点
栈
(Stack)		 栈顶 (Peek): O(1)
非栈顶: O(n) 		栈顶 (Push): O(1) 不适用
受限于 LIFO 原则，通常借助辅助栈或转换为数组排序
  • 函数调用栈与递归恢复
  • 括号匹配与算术表达式求值
  • 浏览器历史记录（后退功能）
  • 单调栈求最近极值问题
  • 有效的括号 (Valid Parentheses)
  • 最小栈 (Min Stack)
  • 每日温度 / 下一个更大元素 (单调栈)
  • 逆波兰表达式求值
堆
(Heap / Priority Queue)		 极值 (堆顶): O(1)
非极值: O(n) 		插入节点: O(log n)
建堆 (Heapify): O(n) 		堆排序: O(n log n)
原地排序，空间复杂度 O(1)
  • 优先队列（操作系统任务调度）
  • Top K 海量数据筛选
  • Dijkstra / Prim 图算法路径优化
  • 双堆法实时维护数据流中位数
  • 数组中的第 K 个最大元素
  • 前 K 个高频元素
  • 合并 K 个升序链表 (多路归并)
  • 数据流的中位数 (对顶堆)
队列
(Queue)		 队头 (Peek): O(1)
非队头: O(n) 		队尾 (Enqueue): O(1) 不适用
受限于 FIFO 原则，通常不直接在队列内排序
  • 图/树的广度优先搜索 (BFS)
  • 消息队列（异步处理与限流解耦）
  • 打印机/服务请求排队缓冲
  • 单调队列维护滑动窗口极值
  • 用队列实现栈 / 用栈实现队列
  • 二叉树的层序遍历
  • 滑动窗口最大值 (单调队列)
  • 腐烂的橘子 (BFS 遍历)
