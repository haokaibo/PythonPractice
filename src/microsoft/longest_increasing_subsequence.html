Longest Increasing Subsequence — Visual Walkthrough

Patience sorting / DP with binary search. Maintain a tails array where tails[i] is the smallest possible tail of any increasing subsequence of length i+1. For each num, use bisect_left to find the slot: append when num extends a longer subsequence, otherwise replace the existing tail to keep it minimal. Time complexity O(n log n), space O(n).
